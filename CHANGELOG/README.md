# Changelog

All notable changes to [`atlbase`](https://crates.io/crates/atlbase) are documented here: new
functions, functions whose behavior or call changed, and functions that were removed (with the
reason and the replacement).

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/). Before 1.0 a
change of the minor version (`0.x`) may break the API. There is one file per version series
(`v.0.2.x.md` holds 0.2.0, 0.2.1, …). The same text is shown as a web page, which is built from
these files: `docs/index.html` reads this list and loads every file in it.

## Versions

Newest first. A new series needs a new file and a line here; `cargo test --test changelog`
checks that the list and the files fit together.
